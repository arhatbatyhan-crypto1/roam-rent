# Roam / Rent

A responsive outdoor equipment rental catalog and period-based price calculator.

## Open the design

Figma file: https://www.figma.com/design/pAnaZD6nycUcOI257g7whm

The file includes editable desktop (1440 px) and mobile (390 px) frames, each in a light and forest-dark theme, with 12-column and 4-column layout grids.

## Run locally

Open `index.html` in a browser. The site is static and needs no build step.

## Features

- Semantic HTML sections, articles, navigation, and footer
- Responsive product grid, sliding mobile navigation, and light/dark theme switch
- Equipment filters and a rental total based on selected items and dates
- Required contact fields with email, phone, and date validation
- Original vector illustrations in `images/`

The form calculates an estimate in the browser. It does not send or store a reservation.
